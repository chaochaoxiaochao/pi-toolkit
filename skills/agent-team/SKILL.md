当前会话是**主 Agent**，负责核心调度：按配置中的模型和角色启动独立子代理，分派用户问题，收集结果并维护调查档案。主 Agent 根据结果决定直接回答、补充核验或继续下一轮。子代理不需要常驻；跨轮连续性来自持久调查档案和逻辑成员身份，而不是聊天记忆。

## 调用方式

用户通过 `/skill:agent-team` 显式加载后开启。此 skill 不参与模型自动选择；高代价决策也不构成自动加载或启动的授权。

## 1. 建立调查档案

为当前问题建立 `.pi/agent-team/<case>/`：

```text
.pi/agent-team/<case>/
├── BRIEF.md              # 问题、范围、术语、输入和排除项
├── FINDINGS-stageN.md    # 当前唯一事实源；新阶段整体取代旧阶段
├── LEDGER.md             # 只增不改的 N/X 记录
└── rounds/
    └── N.md              # 本轮成员、模型、角色和分派问题
```

`BRIEF.md` 只记录稳定背景。`FINDINGS-stageN.md` 记录当前问题、编号发现及证据、已推翻结论和待处理项。`LEDGER.md` 中发现按 `N1, N2…` 追加，被推翻的结论按 `X1, X2…` 追加并写明推翻者。只有主 Agent 能更新这三个权威文件；子代理只提交结果和候选证据。

## 2. 配置成员与角色

读取本 skill 同目录的 [models.json](models.json)：`members` 是成员与模型的唯一配置来源，`roles` 是角色职责的唯一配置来源。默认将两个数组按顺序一一对应；配置为空或数量不匹配时，报告配置问题后再启动。

按配置成员数并发启动子代理，显式传入各自的 `model`，并将对应角色的 `charter` 放入任务。使用 Persona 派发时，成员统一选择 `agent: "analyst"`，作为中立执行载体；具体职责由本轮 `charter` 注入。成员使用相同的中性只读执行约束。启动后核对并在本轮记录中写下每个任务实际生效的模型；无法确认或与配置不符时，该成员结果无效并报告原因。

每轮在 `rounds/N.md` 写明成员、模型、角色、输入文件和分派问题。默认沿用角色映射；需要交叉复核时可轮换，并记录新的映射。

## 3. 交底与通信

拓扑是星型，主 Agent 是唯一消息路由。成员在同一轮中独立作答，在提交前不得看到其他成员本轮答案。需要逻辑成员 A 复核逻辑成员 B 的上一轮结论时，由主 Agent 在新任务中引用 B 的原话和证据位置；不能假定新实例记得上一轮聊天。

下行给用户问题、角色职责、具体任务和文件指针：每个成员阅读 `BRIEF.md`、最新 `FINDINGS-stageN.md`、`LEDGER.md` 和本轮文件，使用档案恢复背景。上行结果必须能归属到轮次和成员，并包含结论、证据位置和未解决问题；长结果写入持久文件，不能依赖截断的终端文本。

## 4. 回合

一轮 = 记录受保护文件和工作树初始状态 → 写本轮任务 → 配置成员并发独立分析 → 主 Agent 收齐结果或失败报告 → 检查子代理未修改项目或权威文件 → 汇总并核验关键证据 → 更新 FINDINGS 和 LEDGER → 决定收尾或继续。

每个成员收到范围明确、可检查结果的任务。例如“查 `adbconnection.cc`，确认该错误日志与被销毁的 fd 是否 1:1”。只有存在需要补证、复核或继续处理的问题时才开下一轮，并写明目标；子代理结束后即可释放。

## 5. 纪律

- **独立性**：同轮答案不得互相可见；成员之间不直接通信。
- **只读完整性**：只读是协议约束，不假定执行环境构成沙箱。每轮结束后比较初始状态；发现子代理修改项目或权威文件时，该成员结果无效并显式报告污染范围。
- **更正**：结论被推翻时，明确记录更正及依据，并追加对应 X。
- **证据**：区分直接证据、实测、推断和未知；结论附证据位置。
- **分歧**：根据证据说明支持、推翻或未决；未决项写明缺失证据，不以多数投票或折中平均替代核验。
- **缺席视角**：成员失败或额度耗尽时，明确记录缺失的模型和方法角色，不能把不完整轮次当成完整评审。

## 6. 按需核验与收尾

主 Agent 根据问题需要选择角色轮换、跨模型独立复算、阴性对照或开放攻击。开放攻击时，由各成员自行选择其认为最强的反证方向。这些是补充核验手段，不是每次分析的必经步骤；任务仍须遵循所分配角色的 `charter`。

当用户问题已有足够证据支持的回答，或剩余问题受缺失输入、工具或权限阻塞时，可以收尾。最终回答汇总结论及依据，单列未解决问题、失败或缺席成员，以及需要人或设备批准的动作；受阻停止时明确说明限制，不宣称已经收敛。
