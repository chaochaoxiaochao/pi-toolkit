# Domain Docs

This repository uses a single domain context.

## Before exploring

Read these when they exist:

- `CONTEXT.md` at the repository root
- relevant ADRs under `docs/adr/`

If they do not exist, proceed silently. Domain-modeling creates them lazily when terminology or decisions need recording.

## Vocabulary

Use terms defined in `CONTEXT.md` consistently in issues, proposals, hypotheses, and tests. Reconsider undefined terminology or record a genuine vocabulary gap for domain-modeling.

## ADR conflicts

Explicitly identify proposals that contradict an existing ADR instead of silently overriding it.
